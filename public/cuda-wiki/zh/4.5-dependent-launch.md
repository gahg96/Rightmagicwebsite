# 4.5 可编程依赖启动与同步

可编程依赖启动（Programmatic Dependent Launch）机制允许依赖的次级核函数在同一 CUDA 流中、在它所依赖的主核函数执行完毕之前就启动。自计算能力 9.0 的设备起可用。当次级核函数可以完成大量不依赖主核函数结果的工作时，该技术可以带来性能收益。

可编程依赖启动对 CUDA 核函数启动 API 做了修改，如下节所述。这些 API 需要至少计算能力 9.0 才能提供重叠执行。

## 4.5.2 API 说明

在可编程依赖启动中，主核函数和次级核函数在同一个 CUDA 流中启动。当主核函数准备好启动次级核函数时，所有线程块都应执行 `cudaTriggerProgrammaticLaunchCompletion`。次级核函数必须使用如下所示的可扩展启动 API 启动。

```cpp
__global__ void primary_kernel() {
   // 应在启动次级核函数之前完成的初始工作

      // 触发次级核函数
      cudaTriggerProgrammaticLaunchCompletion();

      // 可与次级核函数同时进行的工作
}

__global__ void secondary_kernel()
{
   // 独立工作

      // 将阻塞，直到次级核函数所依赖的所有主核函数
      // 已完成并将结果刷新到全局内存
      cudaGridDependencySynchronize();

      // 依赖工作
}

cudaLaunchAttribute attribute[1];
attribute[0].id = cudaLaunchAttributeProgrammaticStreamSerialization;
attribute[0].val.programmaticStreamSerializationAllowed = 1;
configSecondary.attrs = attribute;
configSecondary.numAttrs = 1;

primary_kernel<<<grid_dim, block_dim, 0, stream>>>();
cudaLaunchKernelEx(&configSecondary, secondary_kernel);
```

当次级核函数使用 `cudaLaunchAttributeProgrammaticStreamSerialization` 属性启动时，CUDA 驱动可以安全地提前启动次级核函数，而无需等待主核函数的完成和内存刷新。

当所有主线程块都已启动并执行了 `cudaTriggerProgrammaticLaunchCompletion` 后，CUDA 驱动即可启动次级核函数。如果主核函数未执行该触发，则在主核函数的所有线程块退出后隐式触发。

无论哪种情况，次级线程块都可能在主核函数写入的数据可见之前启动。因此，当次级核函数配置了可编程依赖启动时，必须始终使用 `cudaGridDependencySynchronize` 或其他手段验证主核函数的结果数据可用。

请注意，这些方法为两个核函数的并发执行提供了机会，但这种行为是机会性的，不保证会导致并发的核函数执行。以这种方式依赖并发执行是不安全的，可能导致死锁。

## 4.5.3 在 CUDA 图中使用

可编程依赖启动可通过流捕获或直接通过边数据在 CUDA 图中使用。要在带边数据的 CUDA 图中编程此功能，可在连接两个核函数节点的边上使用 `cudaGraphDependencyType` 值为 `cudaGraphDependencyTypeProgrammatic` 的边类型。该边类型使上游核函数对下游核函数中的 `cudaGridDependencySynchronize()` 可见。该类型必须与 `cudaGraphKernelNodePortLaunchCompletion` 或 `cudaGraphKernelNodePortProgrammatic` 的输出端口一起使用。

流捕获对应的图等价形式如下：

| 流代码（缩写） | 对应的图边 |
|---|---|
| `cudaLaunchAttribute attribute;`<br>`attribute.id = cudaLaunchAttributeProgrammaticStreamSerialization;`<br>`attribute.val.programmaticStreamSerializationAllowed = 1;` | `cudaGraphEdgeData edgeData;`<br>`edgeData.type = cudaGraphDependencyTypeProgrammatic;`<br>`edgeData.from_port = cudaGraphKernelNodePortProgrammatic;` |
| `cudaLaunchAttribute attribute;`<br>`attribute.id = cudaLaunchAttributeProgrammaticEvent;`<br>`attribute.val.programmaticEvent.triggerAtBlockStart = 0;` | `cudaGraphEdgeData edgeData;`<br>`edgeData.type = cudaGraphDependencyTypeProgrammatic;`<br>`edgeData.from_port = cudaGraphKernelNodePortProgrammatic;` |
| `cudaLaunchAttribute attribute;`<br>`attribute.id = cudaLaunchAttributeProgrammaticEvent;`<br>`attribute.val.programmaticEvent.triggerAtBlockStart = 1;` | `cudaGraphEdgeData edgeData;`<br>`edgeData.type = cudaGraphDependencyTypeProgrammatic;`<br>`edgeData.from_port = cudaGraphKernelNodePortLaunchCompletion;` |
